This application is able to minimise all running applications into the dock. This can mimic the Windows+M keyboard shortcut. The code uses accesibility options and listen to a keyboard short cut. The default is Control+Option+Command M

The code was created on a fully wibe coded mode by Claude Code

Install: you can compile it on mac os by XCode or you can download the prebuilt Minimize-<version>.dmg file from the releases.
